Methodology

1. Retrieve OSM bus stops, platforms, stop positions, railway stations and route relations within the national bounding box.

2. Display mapped stop locations and route-member ways.

3. Generate optional 500 m straight-line buffers around mapped stops.

4. Summarise features within a selected administrative polygon when a boundary file is uploaded.

5. Calculate mapped-stop density per 100 km² where the selected area geometry is available.

Proximity buffers do not represent pedestrian-network distance or actual service availability.
